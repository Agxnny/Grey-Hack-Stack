# Project philosophy

Decision: 2026-11-24 — user-directed, gameplay-first progression.

Grey Hack Stack is a learning project as well as a software project. The player is new to Grey Hack and wants to learn normal gameplay rather than immediately pursue advanced or endgame systems.

## Principles

- Learn tasks manually before automating them.
- Begin with simple utilities and small GreyScript experiments.
- Introduce abstractions, shared datasets and infrastructure only when justified by practical needs.
- Avoid unnecessary spoilers, progression shortcuts and premature optimisation.
- Advance when the player understands the underlying mechanics, not merely when code is complete.
- Support both modes where practical; use offline play for isolated experiments and respect online rules.
- The API inventory is a reference, not an implementation checklist. Exhaustive verification is not a prerequisite for learning gameplay.

## Initial learning sequence (provisional)

1. Desktop, tutorial, terminal and filesystem.
2. Basic computers, networking and game terminology.
3. Beginner missions performed manually.
4. Simple scripts addressing encountered needs.
5. Normal economic and equipment progression.
6. Services, owned infrastructure and reusable utilities as encountered.
7. Shared data and automation only once recurring needs justify them.
8. Advanced mechanics and coordinated software later.

The sequence is flexible and follows the player's actual experience. Do not assume an advanced gameplay starting point.
